Esteira de Sushi

Segure o dedo numa coluna para mandar os ingredientes do topo para a esteira.

Os clientes pedem o prato pronto, mas das colunas saem ingredientes: para o nigiri de polvo, mande um tentáculo; para o de salmão, o filé clarinho; para o de atum, o bloco vermelho…

O ingrediente dá uma volta inteira e, ao passar de novo pelo chef, vira o prato. Só aí o cliente pega.

Sobreviva até o fim do tempo sem deixar a esteira lotar. Quanto mais cheia, mais devagar ela anda!
